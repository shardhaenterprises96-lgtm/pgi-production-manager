## 1. Salesman Role Restrictions

### Catalog View

* Hide all product prices from Salesman users.
* Salesman should only see:

  * Product Image
  * Product Name
  * SKU/Item Code
  * GST %
  * Available Stock

### Filters

* Remove advanced filters from Salesman Catalog.
* Keep only basic search if already available.

### Invoice Visibility

* Salesman should only be able to view invoices from the last 7 days.
* Older invoices should not be visible to Salesman.

## 2. Multi-Product Selection & Order Creation

### Catalog Selection

* Allow Salesman to select one or multiple products.
* Add quantity input field (number only).
* User can enter quantity directly.

### Proceed Action

* Enable "Proceed to Order" button when at least one product is selected.
* Selected products should be added to the order screen automatically.

## 4. GST Handling

### Product Creation

Admin must enter:

* Product Name
* Retail Price (GST Inclusive)
* GST Rate (%)

### Catalog Display

Show:

* GST %
* Retail Price

### Billing

System should:

* Automatically calculate GST breakup.
* Calculate CGST/SGST or IGST where applicable.
* Use GST-inclusive price entered by Admin.
* No manual GST calculation required during billing.

Allow Admin to select:

1. Sequential

   INV-0001

2. Date + Serial
   Example:
   INV-20260805-001

   Example:
   INV-2026-08-001

* Never Reset

* Orders

* Set Prefix
